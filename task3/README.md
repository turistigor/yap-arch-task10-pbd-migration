## Инструменты защиты

**Шифрование at Rest**
- Использование AES для шифрование отдельных полей на уровне БД, содержащих чувствительные данные.
- Использование БД со встроенными механизмами шифрования для критически важных данных (Postgres Pro Certified/Red Database).
- HashiCorp Vault для хранения ключей.

**Шифрование in Transit**
- TLS для передачи данных.
- WireGuard VPN и SSH для удалённого доступа.

**Обфускация и маскировка**
- Токенизатора в сервисе Payment для сокрытия сохраненных данных банковских карт.
- Средств маскировки в коде для ограничения видимости чувствительных данных.

**Ограничение доступа**
- IAM (Keycloak/Okta/Casdoor) для аутентификации, авторизации пользователей, реализации RBAC на уровне приложения;
- Встроенные механизмы K8s для ограничения доступа на уровне сети (Network Policies) кластера и RBAC.

## Автоматизированный контроль

- Data Governance (BigID/DataHub) для Data Lineage (автоматическое тегирование, мониторинг, аудит).
- SIEM (QRadar/Sentinel/SearchInform) для мониторинга событий безопасности в системе.
- CI/CD - проверки в пайплайнах.

## Реестр программных и аппаратных средств для защиты данных

| Средство | Доступные реализации | Применение |
|---|---|---|
| Data Governance  | BigID/DataHub                        | Автоматическое тегирование, ограничение, мониторинг и аудит доступа к данным |
| БД с шифрованием | Postgres Pro Certified, Red Database | Шифрование данных по 152-ФЗ (PII), 323-ФЗ (PHI), 161-ФЗ (PCI)|
| KMS              | HashiCorp Vault                      | Хранение ключей шифрования |
| IAM              | Keycloak/Okta/Casdoor                | Ограничение доступа к чувствительным данным (PII, PHI и PCI) |
| SIEM             | QRadar/Sentinel/SearchInform         | Логин, изменение прав доступа, операции с чувствительными данными и т.д. |
| Оркестратор      | Kubernetes                           | Развертывание компонентов системы с ограничением взаимодействий (RBAC, Network Policies) |
| API Gateway      | Nginx, Apisix, Kong                  | Контроль нагрузки, логирование, аутентификация |
| Message Broker   | Kafka / RabbitMQ                     | Контроль нагрузки, уменьшение риска DDos |
| ETL              | Airflow                              | Обезличивание данных для аналитики |
| OLAP             | ClickHouse                           | Обезличивание данных для аналитики |
| HSM              | КриптоПро HSM                        | Безопасная генерация и надежное хранение криптографических ключей, выполнение операций шифрования |
| VPN              | WireGuard VPN                        | Безопасный удаленный доступ к инфраструктуре компании |
| CI/CD            | GitLab, Jenkins                      | Проверки в пайплайнах: уязвимости зависимостей, секреты в коде, проверки по тегами др. |
